# 方案硬件概要设计Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | 需求确认 |
| 2.0 | 系统架构 |
| 3.0 | 电源 |
| 4.0 | 关键器件选型 |
| 5.0 | 可生产性设计 |
| 6.0 | 可靠性设计 |
| 7.0 | 信号质量 |
| 8.0 | 高风险项和备选方案 |

### 1.0 需求确认

| 检查内容 |
|------|
| 明确电源管理、数据处理、通信接口、对外接口等要求 |
| 明确处理速度、传输速率、带宽、功耗等要求 |
| 明确温度、湿度、抗震、EMC等要求 |
| 与SE、软件、机构、测试团队对齐需求 |

### 2.0 系统架构

| 检查内容 |
|------|
| 已绘制系统框图（Block Diagram）并明确各模块功能 |
| 定义关键接口（通信协议、电气特性、机械接口） |

### 3.0 电源

| 检查内容 |
|------|
| 规划电源树（Power Tree）和各模块电压/电流需求 |
| 明确输入电源范围（如DC 5V±10%） |
| 明确输出电源的要求（如电压、带载能力、纹波） |
| 明确上电时序要求、浪涌保护和冗余设计等 |

### 4.0 关键器件选型

| 检查内容 |
|------|
| 明确主控芯片、电源芯片、存储芯片、传感器、连接器等关键器件的选型、价格和供货周期。 |

### 5.0 可生产性设计

| 检查内容 |
|------|
| 确认下载和升级方式，并预留测试点 |
| 预留测试点，如如JTAG、UART、LED状态灯，方便故障排查 |

### 6.0 可靠性设计

| 检查内容 |
|------|
| 外接端口预留TVS和ESD等防静电和浪涌设计 |
| 考虑降额设计（如电容电压、MOSFET电流） |

### 7.0 信号质量

| 检查内容 |
|------|
| 识别高速信号（如PCIe、DDR、USB）并规划层叠结构 |
| 评估EMC设计（滤波、接地、屏蔽），预留端接电阻、阻抗匹配和屏蔽措施 |

### 8.0 高风险项和备选方案

| 检查内容 |
|------|
| 识别高风险项，并跟项目经理和 SE 确认 |
| 是否有备用方案或其它规避措施？ |
