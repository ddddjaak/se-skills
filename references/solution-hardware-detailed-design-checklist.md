# 硬件详细设计Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | 器件选型与封装 |
| 2.0 | 原理图 |
| 3.0 | PCB |
| 4.0 | 文档控制 |

### 1.0 器件选型与封装

| 检查内容 |
|------|
| 元器件是否满足性能、温度范围和寿命要求？ |
| 器件原理图和PCB封装是否正确？ |
| 器件供货周期和库存是否ok？ |
| 关键器件和风险器件是否有替代方案？ |

### 2.0 原理图

| 检查内容 |
|------|
| 电源网络是否完整（电压等级、电流容量、去耦电容等）？ |
| 电源方案是否满足效率、纹波和动态响应要求？ |
| 输入/输出保护（如反接、短路）是否完备？ |
| 信号完整性是否考虑（阻抗匹配、端接电阻、串扰等） |
| 关键信号（高速、时钟、差分）布局走线是否合理？ |
| 保护电路（ESD、过压、过流）是否齐全？ |

### 3.0 PCB

| 检查内容 |
|------|
| 层叠设计是否合理（层数、材质、厚度）？ |
| 布局是否满足散热、EMC和机械结构要求？ |
| 电源走线是否合理，宽度是否满足过流要求？ |
| 关键信号线是否满足长度、间距和阻抗控制要求？ |
| 电源平面和地平面分割是否合理（避免噪声耦合）？ |
| 是否设计测试点（关键信号、电源、地）？ |
| 是否预留调试接口（如UART、JTAG）？ |
| 是否满足硬件测试需求（功能、性能、可靠性）？ |
| 元器件布局是否满足贴片/焊接工艺要求？ |
| 导出dxf文件，检查与结构的配合是否ok？ |
| 丝印和标注是否清晰可读？ |

### 4.0 文档控制

| 检查内容 |
|------|
| 设计文件（原理图、PCB、BOM）是否准确并归档？ |
| 所有改版是否有设计变更和评审记录并归档？ |
