## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 | 评估 |
|------|--------|------|
| 1.0 | 器件选型与封装 | NO |
| 2.0 | 原理图 | NO |
| 3.0 | PCB | NO |
| 4.0 | 文档控制 | NO |

### 1.0 器件选型与封装

**评估**: NO

| 检查内容 | 评估 | 类别 | 状态 |
|------|------|------|------|
| 元器件是否满足性能、温度范围和寿命要求？ | No |  | OK |
| 器件原理图和PCB封装是否正确？ | No |  | OK |
| 器件供货周期和库存是否ok？ | No |  | OK |
| 关键器件和风险器件是否有替代方案？ | No |  | OK |

### 2.0 原理图

**评估**: NO

| 检查内容 | 评估 | 类别 | 状态 |
|------|------|------|------|
| 电源网络是否完整（电压等级、电流容量、去耦电容等）？ | No |  | OK |
| 电源方案是否满足效率、纹波和动态响应要求？ | No |  | OK |
| 输入/输出保护（如反接、短路）是否完备？ | No |  | OK |
| 信号完整性是否考虑（阻抗匹配、端接电阻、串扰等） | No |  | OK |
| 关键信号（高速、时钟、差分）布局走线是否合理？ | No |  | OK |
| 保护电路（ESD、过压、过流）是否齐全？ | No |  | OK |

### 3.0 PCB

**评估**: NO

| 检查内容 | 评估 | 类别 | 状态 |
|------|------|------|------|
| 层叠设计是否合理（层数、材质、厚度）？ | No |  | OK |
| 布局是否满足散热、EMC和机械结构要求？ | No |  | OK |
| 电源走线是否合理，宽度是否满足过流要求？ | No |  | OK |
| 关键信号线是否满足长度、间距和阻抗控制要求？ | No |  | OK |
| 电源平面和地平面分割是否合理（避免噪声耦合）？ | No |  | OK |
| 是否设计测试点（关键信号、电源、地）？ | No |  | OK |
| 是否预留调试接口（如UART、JTAG）？ | No |  | OK |
| 是否满足硬件测试需求（功能、性能、可靠性）？ | No |  | OK |
| 元器件布局是否满足贴片/焊接工艺要求？ | No |  | OK |
| 导出dxf文件，检查与结构的配合是否ok？ | No |  | OK |
| 丝印和标注是否清晰可读？ | No |  | OK |

### 4.0 文档控制

**评估**: NO

| 检查内容 | 评估 | 类别 | 状态 |
|------|------|------|------|
| 设计文件（原理图、PCB、BOM）是否准确并归档？ | No |  | OK |
| 所有改版是否有设计变更和评审记录并归档？ | No |  | OK |
