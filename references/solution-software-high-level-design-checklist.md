# 方案软件概要设计 Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | 设计需求概述项检查 |
| 2.0 | 模块设计项检查 |
| 3.0 | 需求追溯项检查 |
| 4.0 | 重用性检查 |
| 5.0 | DFX设计项检查 |
| 6.0 | 设计难点与解决措施项检查 |

### 1.0 设计需求概述项检查

| 检查内容 |
|------|
| 是否列出清晰的设计目标 |
| 是否列出清晰的功能 / 性能需求 |
| 是否列出DFX需求、约束假定、运行环境、组件间关系 |

### 2.0 模块设计项检查

| 检查内容 |
|------|
| 模块设计是否跟前面接口设计一致 |
| 模块设计是否高内聚低耦合 |
| 模块功能描述和接口是否清晰 |

### 3.0 需求追溯项检查

| 检查内容 |
|------|
| 模块设计与需求间的承接是否清晰明确 |

### 4.0 重用性检查

| 检查内容 |
|------|
| 是否考虑对以往模块 / 组件的继承复用 |
| 是否会使用到FOSS（开源免费软件） |
| 如使用到FOSS（开源免费软件），是否评估过影响 |

### 5.0 DFX 设计项检查

| 检查内容 |
|------|
| 对效率的考虑是否足够 |
| 对兼容性的考虑是否足够 |
| 对可移植性的考虑是否足够 |
| 对可扩展的考虑是否足够 |
| 对可靠性的考虑是否足够 |
| 对可维护性的考虑是否足够 |
| 对可重用的考虑是否足够 |
| 对安全性的考虑是否足够 |
| 对集成与测试的考虑是否足够 |

### 6.0 设计难点与解决措施项检查

| 检查内容 |
|------|
| 是否评估过设计难点 |
| 如果有设计难点，是否有妥善的解决措施 |
