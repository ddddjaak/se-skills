# 方案量产测试策略 Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | Configuration Items Check （测试过程域配置项检查） |
| 2.0 | Basic Information Check（基本的信息检查） |
| 3.0 | Requirement Traceability Check （测试项目识别检查） |
| 4.0 | Requirement Normalization Check （测试分析检查） |
| 5.0 | Requirement Classification Check （测试设计分类检查） |

### 1.0 Configuration Items Check（需求过程域配置项检查）

| 编号 | 检查内容 |
|------|------|
| CIC1 | 是否有沟通记录 |
| CIC2 | 是否有软硬件技术要求或规格 |
| CIC3 | 是否有软硬件详设或规范 |

### 2.0 Basic Information Check（基本的信息检查）

| 编号 | 检查内容 |
|------|------|
| BIC1 | 引用文档的版本、发布日期是否记录清晰？ |
| BIC2 | 产品特性分析、可测试性分析、测试流程、测试设计章节是否有为空？ |
| BIC3 | 测试分析字段是否按要求填写？ |
| BIC4 | 如有特殊需求是否已标注出来？ |

### 3.0 Requirement Traceability Check （测试项目识别检查）

| 编号 | 检查内容 |
|------|------|
| RTC1 | 每条测试设计是否都按要求填写？ |
| RTC2 | 针对产品特性，测试项目是否有遗漏？ |
| RTC3 | 测试项目与测试设计是否对应？ |

### 4.0 Requirement Normalization Check （测试分析检查）

| 编号 | 检查内容 |
|------|------|
| RNC1 | 测试分析字段是否按要求填写？ |
| RNC2 | 测试分析是否包含主要接口特性？ |
| RNC3 | 测试分析是否包含主要功能特性？ |
| RNC4 | 测试分析是否包含主要性能特性？ |

### 5.0 Requirement Classification Check （测试设计分类检查）

| 编号 | 检查内容 |
|------|------|
| RCC1 | 测试设计与测试分析是否对应？ |
| RCC2 | 测试设计是否可操作？ |
