# 方案软件详细设计Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | 设计需求概述项检查 |
| 2.0 | 模块设计项检查 |
| 3.0 | 需求追溯项检查 |
| 4.0 | 设计难点与解决措施项检查 |

### 1.0 设计需求概述项检查

| 检查内容 |
|------|
| 是否列出清晰的设计目标 |
| 是否列出清晰的功能 / 性能需求 |
| 是否列出DFX需求、约束假定、运行环境、组件间关系 |

### 2.0 模块设计项检查

| 检查内容 |
|------|
| 代码开发是否符合方案软件开发规范（包括编码规则） |
| 是否按自测用例完成了开发自测 |
| 单元功能描述和接口是否清晰 |
| 是否用状态转换图/顺序图/消息序列图/用例图等描述模块内部的软件单元之间的动态行为，如任务、线程、时间片、中断等 |
| 函数详细设计是否清晰定义函数传入参数的名称、含义、数据类型、取值范围，以及返回值的类型、含义、取值范围。 |
| 函数详细设计是否体现函数实现逻辑的流程图（逻辑简单的函数可忽略） |

### 3.0 需求追溯项检查

| 检查内容 |
|------|
| 单元设计与需求间的承接是否清晰明确 |
| 如果有同类项目的历史缺陷，是否已规避 |

### 6.0 设计难点与解决措施项检查

| 检查内容 |
|------|
| 是否评估过设计难点 |
| 如果有设计难点，是否有妥善的解决措施 |
