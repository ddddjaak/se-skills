# 方案测试报告 Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | Configuration Items Check （测试过程域配置项检查） |
| 2.0 | Basic Information Check（基本的信息检查） |
| 3.0 | Requirement Traceability Check （测试项目检查） |
| 4.0 | Requirement Normalization Check （测试执行规范检查） |
| 5.0 | Requirement Classification Check （测试结果检查） |

### 1.0 Configuration Items Check （测试过程域配置项检查）

| 编号 | 检查内容 |
|------|------|
| CIC1 | 是否有沟通记录 |
| CIC2 | 是否有软硬件技术要求或规格 |
| CIC3 | 是否有软硬件详设或规范 |

### 2.0 Basic Information Check（基本的信息检查）

| 编号 | 检查内容 |
|------|------|
| BIC1 | 测试项是否条目化？ |
| BIC2 | 测试结果字段是否按要求填写？ |
| BIC3 | 整体测试结论是否记录清晰？ |
| BIC4 | 如有特殊需求是否已标注出来？ |

### 3.0 Requirement Traceability Check （测试项目检查）

| 编号 | 检查内容 |
|------|------|
| RTC1 | 每个测试项是否都清晰标注（已测/未测/部分测试）状态？ |
| RTC2 | 每个测试项是否都清晰标注测试结论？ |

### 4.0 Requirement Normalization Check （测试执行范检查）

| 编号 | 检查内容 |
|------|------|
| RNC1 | 测试版本、时间、地点、人员信息是否记录清楚？ |
| RNC2 | 测试环境说明是否包含业务组网说明？ |
| RNC3 | 测试使用的量具、设备是否有清楚的记录名称、数量、型号、有效期？ |
| RNC4 | 测试执行统计是否按字段记录清晰？ |
| RNC5 | 详细测试结果是否按字段记录清晰？ |
| RNC6 | 缺陷统计是否明确了TOP问题和缺陷闭环情况？ |
| RNC7 | 遗留问题是否按字段记录清晰？ |

### 5.0 Requirement Classification Check （测试结果检查）

| 编号 | 检查内容 |
|------|------|
| RCC1 | 每一项的详细测试结果对应的测试结论是否正确？ |
| RCC2 | 遗留问题是否与详细测试结果相对应？ |
