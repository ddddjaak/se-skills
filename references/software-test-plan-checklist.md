# Software Development Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | Configuration Items Check（过程域配置项检查） |
| 2.0 | Basic Information Check（基本的信息检查） |
| 3.0 | Test Scheme Rule Check（测试方案检查） |

### 1.0 Configuration Items Check（需求过程域配置项检查）

| 编号 | 检查内容 |
|------|------|
| CIC1 | 是否有沟通记录 |
| CIC2 | 是否有测试方案输出(在线系统承载或线下文档) |

### 2.0 Basic Information Check（基本的信息检查）

| 编号 | 检查内容 |
|------|------|
| BIC1 | 文档描述是否包含编写目的、项目背景、缩写词定义、专业术语定义、参考资料？ |
| BIC2 | 测试方案输出物的版本是否记录清晰？ |

### 3.0 Test Scheme Rule Check（测试方案检查）

| 编号 | 检查内容 |
|------|------|
| DRC1 | 是否描述了测试范围，包括测试类别、测试入口、测试特殊要求，测试目标和测试对象。 |
| DRC2 | 是否对测试进行合理规划，包括测试方法、测试用例选择、测试日程的规划。 |
| DRC3 | 是否描述了测试环境，包括软件环境、硬件环境。 |
| DRC4 | 是否规定了测试工作的管理过程（采用的在线系统或线下的管理工具）。 |
| DRC5 | 是否描述测试结束、终止、中止条件。 |
| DRC6 | 是否描述测试问题的管理过程。 |
