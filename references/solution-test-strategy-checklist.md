# 方案测试策略 Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | Configuration Items Check （测试过程域配置项检查） |
| 2.0 | Basic Information Check（基本的信息检查） |
| 3.0 | Requirement Traceability Check （测试项目识别检查） |
| 4.0 | Requirement Normalization Check （测试策略检查） |
| 5.0 | Requirement Classification Check （测试特性分类检查） |

### 1.0 Configuration Items Check （测试过程域配置项检查）

| 编号 | 检查内容 |
|------|------|
| CIC1 | 是否有沟通记录 |
| CIC2 | 是否有软硬件技术要求或规格 |
| CIC3 | 是否有软硬件详设或规范 |

### 2.0 Basic Information Check（基本的信息检查）

| 编号 | 检查内容 |
|------|------|
| BIC1 | 引用文档的版本、发布日期是否记录清晰？ |
| BIC2 | 产品特性分析、测试分析、测试策略、测试设计章节是否有为空？ |
| BIC3 | 测试设计字段是否按要求填写？ |
| BIC4 | 如有特殊需求是否已标注出来？ |

### 3.0 Requirement Traceability Check （测试项目识别检查）

| 编号 | 检查内容 |
|------|------|
| RTC1 | 每条测试设计是否都按要求填写？ |
| RTC2 | 针对产品特性，测试项目是否有遗漏？ |
| RTC3 | 测试项目与测试设计是否对应？ |

### 4.0 Requirement Normalization Check （测试策略检查）

| 编号 | 检查内容 |
|------|------|
| RNC1 | 测试业务分层模块化是否有遗漏？ |
| RNC2 | 测试设计字段是否按要求填写？ |
| RNC3 | 测试策略中对测试的重点、难点和优先级是否有明确描述？ |
| RNC4 | 针对测试验收标准模糊的测试点，测试策略是否有风险预警？ |
| RNC5 | 测试使用的量具、设备是否有清楚的记录名称、数量、型号、有效期？ |
| RNC6 | 测试策略中对测试的重点、难点和优先级是否有明确描述？ |
| RNC7 | 测试的准入、准出规则是否有遗漏？ |
| RNC8 | 测试人员及进度完成节点是否有遗漏？ |

### 5.0 Requirement Classification Check （测试特性分类检查）

| 编号 | 检查内容 |
|------|------|
| RCC1 | 测试特性分解是否包含对外接口特性？ |
| RCC2 | 测试特性分解是否包含容限特性？ |
| RCC3 | 测试特性分解是否包含容错特性？ |
| RCC4 | 测试特性分解是否包含一致性特性？ |
| RCC5 | 测试特性分解是否包含可靠性特性？ |
