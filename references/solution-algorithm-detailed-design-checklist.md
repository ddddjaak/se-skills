# 方案算法详细设计Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | 适用范围 |
| 2.0 | 算法目的和意义 |
| 3.0 | 算法主要特征 |
| 4.0 | 算法原理 |
| 5.0 | 算法设计 |
| 6.0 | 结果 |
| 7.0 | 总结 |
| 8.0 | 附录 |

### 1.0 适用范围

| 检查内容 |
|------|
| 是否明确定本文档在研发流程中的范围界定 |
| 是否完整描述本文档的可编辑人员范围 |
| 是否完整描述本文档的阅读使用人员范围 |

### 2.0 算法目的和意义

| 检查内容 |
|------|
| 是否描述项目背景 |
| 是否描述项目意义 |
| 是否包含研究历史情况 |
| 是否包含竞品研究 |
| 是否包含需求描述 |

### 3.0 算法主要特征

| 检查内容 |
|------|
| 是否包含算法输入限制和假设 |
| 是否包含名词定义 |
| 是否包含本算法优点 |
| 是否包含本算法的主要特征点 |
| 是否包含本算法的设计背景 |

### 4.0 算法原理

| 检查内容 |
|------|
| 物理原理介绍 |
| 算法数学原理 |
| 算法数学原理的理论推导 |

### 5.0 算法设计

| 检查内容 |
|------|
| 是否包含算法主流程图 |
| 流程图之间是否包含模块关系 |
| 是否包含子流程图 |
| 是否包含参数说明 |
| 是否包含算法中间过程及特征 |

### 6.0 结果

| 检查内容 |
|------|
| 包含数据源介绍（获取方式，数据特征、数据分布等） |
| 统计结果展示（数据图表、图示） |
| 是否包含与需求对比展示 |
| 个例展示 |
| 算法复杂度说明（使用平台、RAM、FLASH占用） |

### 7.0 总结

| 检查内容 |
|------|
| 需求符合说明 |
| 优缺点说明 |
| 方案下一步优化方向说明 |

### 8.0 附录

| 检查内容 |
|------|
| 附录是否包含词算法特殊特性描述 |
| 是否列出引用文档、引用数据集 |
| 所有图表是否清晰可读并附带编号说明？ |
| 是否列出待解决问题清单？ |
