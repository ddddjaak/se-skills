# 方案软件发布评审Checklist

## 检查清单 (CheckList)

### 检查项概览

| 编号 | 检查项 |
|------|--------|
| 1.0 | 需求实现覆盖率检查 |
| 2.0 | 测试覆盖率检查 |
| 3.0 | 软件问题项检查 |
| 4.0 | 软件发布内容检查 |

### 1.0 需求实现覆盖率检查

| 检查内容 |
|------|
| 是否列出清晰的设计目标 |
| 是否列出清晰的功能 / 性能需求 |
| 是否列出DFX需求、约束假定、运行环境、组件间关系 |
| 需求实现覆盖率是否达到 100% |
| 未实现项是否跟相关方达成一致 |

### 2.0 测试覆盖率检查

| 检查内容 |
|------|
| 代码开发是否符合方案软件开发规范（包括编码规则） |
| 是否按自测用例完成了开发自测（覆盖率100%） |
| 是否按方案转测用例完成了方案测试（覆盖率100%） |

### 3.0 软件问题项检查

| 检查内容 |
|------|
| 如果有同类项目的历史缺陷，是否已规避 |
| 软件问题清单中致命和严重缺陷是否已全部close |

### 4.0 软件发布内容检查

| 检查内容 |
|------|
| 源代码工程是否OK |
| HEX等可执行文件是否OK |
| 版本修改说明是否清晰 |
| 版本测试报告是否完整清晰 |
| 软件使用说明是否完整清晰 |
| 测试工具及使用说明是否完整清晰 |
