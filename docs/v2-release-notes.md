# se-skills v2 更新说明

## 一句话总结

**从"16 个独立技能"升级为"一套能自己跑的 SE 工作流引擎"**——给个目标，AI 自动走完需求→架构→规格→审查→追溯全流程。

---

## 六大变化

### 1. 🚀 新增自主模式（/se-goal）

**之前：** 用户要知道该调哪个技能，一步步手动推进。

**现在：** 说一句"端到端走完温度传感器的 SE 全流程"，AI 自动检测阶段 → 执行 → 自检 → 下一阶段。审查发现问题自动修正重试，只在真卡住时才找你。

### 2. 🧭 新增引导模式（Pipeline Mode）

**之前：** "帮我做需求"，AI 反问"16 个技能你要哪个？"

**现在：** AI 自动扫描已有产物，判断你在哪个阶段，展示 2-3 个选项（不说技能名，说产出）。选完→完成→自动问下一步。

### 3. 🔗 技能全连通

每个技能新增"After This Skill"段落，声明上下游依赖。16 个技能从孤岛变成有向图，任何需求可追溯到底。

### 4. 📋 审查清单精简 50%

21 个 checklist 从 4~9 列（检查人/审批人/状态/备注...）精简到 1~2 列（只保留检查项内容）。去掉公司特定元数据，改为通用版。

### 5. 🎯 技能命中率优化

16 个 skill description 全部重写：中文触发词前置、每个唯一标识、显式排除声明，避免"用户说 review，7 个技能抢答"。

### 6. 📦 产物可追溯

新增 versions.json——15 个 artifact 条目、14 条依赖关系、5 个阶段检查点。支持跨会话恢复。

---

## 两种模式

| | 引导式 | 自主式 |
|---|---|---|
| 触发 | "帮我做需求分解" | "端到端走完全流程" |
| 阶段切换 | 展示选项，你选 | AI 自动决定 |
| 验证失败 | 报告给你 | 自查自修（最多 3 次） |
| 适用 | 想一步步把控 | 信任流程，省时间 |

---

## 命令一览

```
/se-goal          自主式：端到端全自动
/se-requirements  引导式：需求分解
/se-architecture  引导式：架构设计
/se-spec          引导式：规格编写
/se-review        引导式：产物审查
/se-traceability  引导式：追溯验证
```
